# Qiqu Wuli Shiyan (Fun Physics Experiments)
# 奇趣物理实验
Over 1700 physics animations covering 11 undergraduate and postgraduate physics courses.
自2024年5月25日起，微信公众号“奇趣物理实验”陆续发布1700余个物理动画，覆盖11门本科、研究生物理课程。

## Covered Courses | 课程清单
- College Physics 大学物理
- Mechanics 力学
- Thermodynamics 热学
- Optics 光学
- Electromagnetism 电磁学
- Atomic Physics 原子物理学
- Theoretical Mechanics 理论力学
- Electrodynamics 电动力学
- Quantum Mechanics 量子力学
- Mathematical Methods in Physics 数学物理方法
- Lattice Vibrational Spectroscopy 晶格振动光谱学
